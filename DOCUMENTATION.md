# Project Documentation

## 1. Project Title

Personal Portfolio Website

## 2. Introduction

This project is a responsive personal portfolio website developed during my Codomax internship. It showcases my skills, education, projects, certifications, and contact information.

## 3. Objective

The main objective of this project is to create a professional and responsive portfolio website using frontend web technologies.

## 4. Technologies Used

- HTML5
- CSS3
- JavaScript

## 5. Features

- Responsive design
- Smooth scrolling
- Interactive buttons
- Hover effects
- Projects section
- Skills section
- Education section
- Certifications section
- Contact form
- Mobile-friendly layout

## 6. Project Structure

- `index.html` – Main webpage
- `style.css` – Website styling
- `script.js` – JavaScript functionality
- `resume.pdf` – Resume
- `README.md` – Project overview
- `DOCUMENTATION.md` – Project documentation

## 7. Projects Included

### AI Medical Assistant
